# The Armature MCP server: plan

> **Moved on 2026-11-21** to the server's own repository, [`mossglenn/armature-mcp`](https://github.com/mossglenn/armature-mcp), as [`docs/plan.md`](https://github.com/mossglenn/armature-mcp/blob/main/docs/plan.md) (its question 12, decided that day). The repository is private for now; until it is opened, this file's history holds the plan as it stood here, decisions included (commit `0bb340a`).

What stands, in brief: an MCP server on the person's machine, its own repository, TypeScript on the MCP SDK's v2 line over stdio, every tool an intelligence read, list filter or slice at a named commit; notes and findings written only on branches other than `main`, by an agent acting for the person (ADR-0067 decision 3), against a workspace hub or a loopback hub under `header` identity, and never against a remote hub (decision 10). Its demonstration is the ICICLE script (`docs/icicle-demo-script.md`). M0 (the scaffold, `describe_hub` and `list_branches`) was built on 2026-11-21; M1 and M4 come before the demonstration's recording.
